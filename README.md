# Книжная полка — учебный веб-магазин

Каталог с фильтрами по жанру/автору и сортировкой по году, покупки (демонстрационная фиксация заказа) и аренда на 14/30/90 дней, остатки, роли покупателя и администратора, управление книжным каталогом, учёт возвратов, уведомления о конце аренды.

## Запуск
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```
Задайте переменные окружения `ADMIN_PASSWORD` (не менее 8 символов, пароль администратора) и при желании `ADMIN_USER` (по умолчанию `admin`) **до первого запуска**. Например, в Windows PowerShell: `$env:ADMIN_PASSWORD="MyStrongPassword123"`; Linux/macOS: `export ADMIN_PASSWORD='MyStrongPassword123'`. После этого `python app.py` и откройте http://127.0.0.1:5000. Зарегистрируйте обычного пользователя самостоятельно.

**Напоминания:** команда `python app.py remind` создаёт уведомления внутри аккаунтов за 2 дня до окончания аренды или при просрочке. Настройте её ежедневный запуск средствами планировщика ОС (cron / Планировщик заданий Windows). Без планировщика команда выполняется вручную. Реальная отправка email/SMS не предусмотрена. Повторный запуск не создаёт дубликаты однотипных уведомлений.

**Ограничения:** списание денег не производится; магазин демонстрационный. Для публичного размещения настройте HTTPS, CSRF, платёжный провайдер, секрет приложения, разграничение прав, резервные копии. База SQLite создаётся автоматически и не должна попадать в репозиторий.
